## インストール
`sudo dnf install rEFInd`の上、

- `/boot/efi/EFI/refind/refind.conf`
- `/boot/efi/EFI/refind/themes/catppuccin/latte-custom.conf`
に各ファイルをコピー

## テーマのインストール

`github.com/catppuccin/refind`の`latte`を
`/boot/efi/EFI/refind/themes/catppuccin/assets/latte`にコピーする

`catppuccin/assets/latte/background.png`のようにアセットがコピーされればok
